## 你好，世界

这是博客的第一篇文章。我使用 **Hugo** 生成静态网站，使用 **PaperMod** 作为主题，并通过 GitHub Pages 免费发布。

以后新增文章时，只需在 `content/posts/` 下创建新的 Markdown 文件，提交到 GitHub，网站就会自动更新。

## 写作方式

这个博客使用 Markdown 写作，支持标题、列表、链接、图片、引用和代码块等常用格式。

```text
content/posts/文章名称/
├── index.md
└── 图片.webp
```

这篇文章只是示例，可以删除，也可以把它改成真正的第一篇文章。
